# Hookah Party

Сайт приглашений на кальянные сборы: регистрация по телефону с SMS-кодом, профиль с аватаром, создание сборов, приглашения и голосование за табаки и чаши.

## Запуск

Откройте `index.html` в браузере. Сборка не нужна.

Демо-вход: `+7 (900) 000-00-01`, пароль `hookah`. Данные хранятся в localStorage браузера, SMS-код показывается на экране.

## Файлы

- `index.html` — разметка, шапка и подвал
- `styles.css` — стили, светлая и тёмная тема
- `app.js` — данные, вход, сборы, каталог
