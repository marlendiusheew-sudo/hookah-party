# Hookah Party

Сайт приглашений на кальянные сборы.

- Регистрация по телефону с SMS-кодом, профиль с аватаром
- Сборы: заведение, ссылки на Яндекс Карты и 2ГИС, приглашения по номеру, голосование за табаки и чашу
- Складчина: число кальянов, цена, сколько с каждого, кто уже скинулся
- Обсуждение внутри сбора, напоминание за час и выгрузка в календарь (.ics)
- Повтор сбора с теми же людьми, редактирование
- Каталог: табаки с отзывами и рейтингом, фильтры по крепости и вкусу, миксы с пропорциями, чаши, аксессуары
- Люди: друзья, страницы пользователей, история сборов, любимое заведение
- Оформление: светлая и тёмная тема, четыре цвета акцента

## Запуск

Откройте `index.html` в браузере. Сборка не нужна.

Демо-вход: `+7 (900) 000-00-01`, пароль `hookah`. Данные хранятся в localStorage браузера, SMS-код показывается на экране.

## Файлы

- `index.html` — разметка, шапка и подвал
- `styles.css` — стили, светлая и тёмная тема
- `app.js` — данные, вход, сборы, каталог
